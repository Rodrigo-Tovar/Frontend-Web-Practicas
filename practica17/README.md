# Practica 17

**¿La ruta protegida hace segura la aplicación? ¿Qué es lo que de verdad protege los datos?**
- La api es la que protege los datos del back, la ruta protegida puede ser eliminada desde el navegador.

**¿Por qué no se manda el miembroId al inscribirse?**
- Porque el id tiene que ser el de la persona ingresada, adjuntar un id puede hacer que alguien agregue un id que no es suyo.

**¿Qué diferencia hay entre un 401 y un 403?**
- 401 es unauthorized, 403 es forbidden.
