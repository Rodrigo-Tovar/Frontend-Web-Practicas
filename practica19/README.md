**¿Qué archivo de Angular hace el papel de main.tsx, de App.tsx y de vite.config.ts?**
- El que hace el papel de main.tsx es main.ts, el de app.tsx lo hace app.ts y vite.config.ts lo hace app.config.ts

**¿Por qué clase() lleva paréntesis y para qué sirve track?**
- Clase es un signal y se llama como función para saber su valor. Track como darle un id del elemento, es para que pueda actualizar el DOM sin afectar elementos que no cambian
