# Practica 18

**¿Cuánto se ahorró y por qué el ahorro es pequeño en esta aplicación?**
- Se ahorraron 4kb. Porque la aplicación no es muy grande, pero si lo fuera ahorraría más.

**¿Por qué falla la API si el preview corre en el puerto 4173?**
- Por los cors ya que no permite al puerto 4173 entonces bloquea las peticiones.

**¿Cuándo conviene un contexto y cuándo un store?**
- Contexto es mejor cuando se comparte información que no cambia mucho a componentes. Store es mejor para manejar un estado en un conjunto de datos en particular para que se actualicen solo ciertas partes de una apliación cuando cambie un dato.
